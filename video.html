Explicación del portal

El espacio web está organizado como un portafolio técnico digital con páginas independientes para presentación, biografía, currículum, proyectos, video, contacto y contenido adicional. La navegación se mantiene constante para que el visitante pueda moverse de forma intuitiva.

El sitio se ha desarrollado únicamente con HTML5 y CSS3. La estructura del contenido se separa de la presentación visual mediante una hoja de estilos externa, lo que facilita el mantenimiento y mejora la claridad del proyecto.

Retos técnicos superados

  • Crear un diseño responsive sin JavaScript
  • Mantener una jerarquía visual clara
  • Usar Grid y Flexbox de forma equilibrada
  • Preparar la estructura para GitHub Pages
  • Cuidar semántica y validación HTML
